# Every advisory for Rust's standard library, and the case that covers it in zustc. Sources: RustSec's advisories for
# the `std` package (https://rustsec.org/packages/std.html, 18), the Rust blog's security advisories, and
# rust-lang/rust's GitHub security advisories. Each case says
# `//@ cve: <id>`; `tests/security.rs` (every_std_cve_has_a_case) keeps this table and the cases in step.
#
# cve	std API	what was wrong	case (or n/a: why)

CVE-2017-20004	MutexGuard	Sync for any T (MutexGuard<Cell<i32>> could be shared)	cve_2017_20004_mutexguard_sync
CVE-2018-1000657	VecDeque::reserve	buffer overflow growing a wrapped ring buffer	cve_2018_1000657_vecdeque_reserve
CVE-2018-1000810	str::repeat	len * n overflowed: a too small buffer written past its end	cve_2018_1000810_str_repeat
CVE-2018-25008	Arc::get_mut	too weak synchronization of the unique-owner check	cve_2018_25008_arc_get_mut
CVE-2019-12083	Error::type_id	overridable: downcast to the wrong type	cve_2019_12083_error_type_id
CVE-2019-1010299	vec_deque::Iter Debug	printed uninitialized slots of the buffer	cve_2019_1010299_vecdeque_iter_debug
CVE-2020-36317	String::retain	a panic in the predicate left invalid UTF-8	cve_2020_36317_string_retain, cve_2020_36317_string_retain_panic
CVE-2020-36318	VecDeque::make_contiguous	popped an element twice (use after free / double free)	cve_2020_36318_vecdeque_make_contiguous
