# リージョン (ライフタイム) 検査、その 6: どこでも同じ代わりの型のリージョンと、借用検査の可変性 (issue #1)

日付: 2026-11-22

その 5 ([2026-11-22-01](2026-11-22-01-region-check-5.md)) は #42 でマージした。その代わりの型のリージョンは、パラメータの型の
値が運ばないところでは新しい変数だった。この段は、そのリージョンを型があるところならどこでも同じものにし、何も呼ばない
ものをもっと検査する。そして、借用についての落ちているテストがいちばん必要としていた、借用検査の可変性の規則を加える。

## 1. 加えたもの

### リージョン検査

- **どこでも同じ代わりの型のリージョン:** 型引数として書いた型 (`with_restriction::<T>(x)`) や、注釈に書いた型
  (`let _: &'static T;`) も、代わりの型の universal なリージョンを持つ。新しいリージョンにはならない。
  - 関門は代わりの型のリージョンを数える。引数がリージョンを持たなくても、`T` を持つ関数は検査する。
  - 代わりの型が長生きすべきリージョンが名前を持たない (`'_`) なら E0311。
- **ライフタイムを書く境界:** 境界 `G: GetRef<'a, isize>` の代わりの型のメソッドは、トレイトのライフタイムを境界が書く
  ものにして呼ぶ。
  - トレイトの宣言が求めること (`fn method<'y: 'x>`) は、呼び出し側が示す。
  - 引数から決まらないトレイトの型パラメータ (`GetRef<'a, T>` の `T`) は、インスタンスにしたシグネチャから取る。
  - そうしたメソッドを呼ぶ関数も、代わりの型のインスタンスを作る。その呼び出しはリージョンについて何かを言うから。
- **トレイトのデフォルトメソッド:** どの impl も使わないトレイトのデフォルトメソッドを、トレイトで縛った代わりの型の
  `Self` で検査する。トレイトのメソッドの呼び出しは、トレイトのライフタイムを名前で取る (`fn b(&self)` の中の、
  `fn a(&'a self)` に対する `self.a()` は「lifetime may not live long enough」)。

### 借用検査

- **`ref` の束縛:** `ref x` / `ref mut x` の束縛と、既定の束縛モードで参照になる束縛は、それ自体は `mut` でない。その
  `&mut x` は E0596。
- **不変の static:** `mut` と宣言していない static、またはその一部への代入は E0594。
- **範囲のスライス:** `&x[a..b]` / `&mut x[a..b]` は x の要素の貸し出し。`&` の向こうなら E0596 で、`&x[i]` と同じように
  衝突する。
- **`mut` でないローカルへのたくさんの借用:** 2 つ以上なら、rustc と同じく、宣言の位置の 1 つのエラーにして、関数の
  ほかのエラーの後に報告する。
- **クロージャ:**
  - 捕捉したものを変更するクロージャは `FnMut`。名前で呼ぶと可変で借りる (束縛が `mut` でなければ E0596)。本体の
    `&mut x;` もそうした変更。
  - 捕捉の `&mut` を持つクロージャは `Copy` でない (2 回ムーブすれば E0382)。
  - `Copy` でない捕捉を本体が外へムーブするクロージャ (`|| drop(v)`) は `FnOnce`。名前で呼ぶとそれを取る (もう 1 回
    呼べば E0382)。
- **値でマッチする配列:** `let [_, _, x] = a;` は `a[2]` をムーブする。それはそれだけの場所。`rest @ ..` は間の要素を
  ムーブする。配列のパターンは、配列そのものを何も調べない。
- **`for x in v`:** 値で回す Vec や配列 (`Copy` でないもの) は、ループが取る。その後で使えば E0382。
- **`Fn` が期待されるところのクロージャ:** 境界が `Fn` を求めるところに渡すクロージャは、捕捉したものを変更できない。
  代入なら E0594、`&mut` や `&mut self` のメソッドなら E0596 で (中のクロージャでも)、変更の位置に報告する。

### #43 のレビュー

- 添字 (`&a[2]`) は、配列のパターンがムーブした要素 (`let [_, _, s] = a;`) を読む。
- `Copy` でない捕捉を変更するだけの move クロージャ (`move || s.push_str("x")`) は `FnMut`。`FnOnce` の判定は、`self` を
  取るメソッドや、一部を値で束縛するパターンを探す (マクロの引数の中も)。
- モジュールの中の不変の static への `m::N = 1` も、`N = 1` と同じく E0594。
- トレイトのデフォルトメソッドのほかの型パラメータ (`G: Get<'b>`) は、自分の境界のライフタイムを持つ。トレイトの
  ライフタイムを取るのは `Self` だけ。
- 境界が `Fn` / `FnMut` を求めるところに名前で渡すクロージャ (`wants_fn(c)`) は、`FnMut` / `FnOnce` でしかなければ、
  クロージャの位置で E0525。
- `for x in v.iter().copied()` / `.cloned()` は v を取らない。実行時にも v を空にしていた (ループの後の v.len() が 0)。
  `.cloned()` は、要素のビットを写さずに、要素ごとに複製する (要素への参照の `Clone::clone`)。

## 4. まだ扱わないもの

- **末尾の式の一時値:** ブロックの末尾の式の一時値は、ブロックのローカルより後、囲む文の終わりまで生きる (edition 2024
  より前)。ブロックのローカルを借りる一時値は E0597 (`nll/issue-54556-*`)。zustc はまだ edition を持たない。
- **射影型と `impl Trait`:** その 5 と同じ。
- **定数の条件:** 借用検査のグラフは、定数の条件では片方の辺だけを取る。そのため `false || { i = 5; true }` は i を
  初期化したことになる (rustc: E0381)。
