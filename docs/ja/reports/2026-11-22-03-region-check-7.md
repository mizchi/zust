# リージョン (ライフタイム) 検査、その 7: 制御フロー、一時値、prelude のメソッドが返すもの (issue #1)

日付: 2026-11-22

その 6 ([2026-11-22-02](2026-11-22-02-region-check-6.md)) は #43 でマージした。この段は、借用検査のグラフ、一時値、prelude の
結果を辿っていなかった場合を扱う。

## 1. 加えたもの

### 借用検査

- **定数の条件:** 借用検査のグラフは、rustc と同じく、定数の条件でも両方の辺を取る。`false || { i = 5; true }` は i を
  初期化しないことがある (E0381)。以前は、定数の条件では片方の辺だけを取っていた。
- **`&&` / `||` の連鎖:** `a && b && c` (演算子が 1 つ) は 1 つの連鎖として下ろす。各項の短絡は終わりへ飛ぶので、c は b の
  後でだけ走る。rustc の制御フローのとおり、`true && { z = 3; true } && z == 3` は z を入れた後で読む。
- **`&*Box::new(1)`:** 呼び出しが作る一時値の deref の借用は、`&f()` と同じく、その一時値の貸し出し。文より長く残る
  ところにしまえば (`m.insert(42, &*Box::new(1))`) E0716。`let` はそれを延ばす。
- **受け手の一時値:** `fn get(&self) -> &A` に対する `let x = mk().get();` では、受け手は文の終わりで解放される一時値。
  その後で x を使えば E0716。メソッドの結果が self を借りないなら (`mk().len()`、結果が `&'static str`) そうしない。
- **prelude のメソッドが返すもの:** prelude の型のメソッドで、結果が参照を持つものは、受け手が持つものを持つ (prelude は
  ライフタイムを書かない)。ローカルのイテレータの `it.next()` や、`raw.iter().map(..).collect()` を返せば E0515。
  `copied` / `cloned` は参照を 1 つ外す。結果が持つのは、その下にあるもので、借用そのものではない
  (`parts.first().copied()` は parts が持つものを持つ)。
  - メソッド呼び出しの連鎖を返すときは、rustc の返す値の範囲のとおり、連鎖の始まりで報告する。
- **move クロージャと `mut` でない捕捉:** `mut` と宣言していないローカルを値で持つ捕捉に、本体が代入する (可変で借りる、
  `&mut self` のメソッドを呼ぶ) なら、変更の位置で E0594 / E0596。捕捉が持つ参照を通した変更 (`t.0: &mut S` に対する
  `t.0.0 = x`) はそうしない。

- **型パラメータのクロージャの呼び出し:** `Fn(..)` / `FnMut(..)` / `FnOnce(..)` で縛った代わりの型は、そのインスタンスの中で、
  境界に照らして呼べる。引数は境界の引数の型で検査し、結果は境界の結果の型の値。`FnMut` は呼ぶ先を可変で借り (`mut` で
  なければ E0596)、`FnOnce` は取り (2 回呼べば E0382)、`Fn` は読む。そうした境界は、もう関数の代わりの型のインスタンスを
  止めない。

### リージョン検査とシグネチャ

- **ライフタイムを書かない型エイリアス:** `type A<'a> = &'a isize` に対する `b: A` は、エイリアスが表すものの 1 つの印。
  そのリージョンは、`&isize` と同じく省略したもの (引数なら新しいもの)。以前は、そうした引数は木を持たず、辿らなかった。
- **struct でない型の impl の E0195:** `impl<'a> Foo<'a> for &'a isize` のメソッドも、struct のものと同じく、トレイトの
  宣言と照らす。メソッド自身の early-bound なライフタイムと、その境界を見る。

### レビューの後

- **rustc と同じ E0195 と E0276 の分け方:** メソッドの early-bound なライフタイムが、トレイトの宣言と数が違うか、宣言で
  late-bound のところで early-bound なら E0195 (`fn f<'a, 'b: 'static>` に対する `fn f<'a: 'static, 'b>`)。同じものなら、
  impl のそれらの間の境界で、宣言の境界から導けないものがあれば E0276 (`fn f<'a: 'b, 'b>` に対する `fn f<'a, 'b: 'a>`)。
  境界が少ない impl は受け入れる。以前は、それぞれの境界の数を比べていて、境界が少ない impl を拒否していた。impl と
  トレイト自身のライフタイムは名前で対応させる (ヘッダのトレイトの引数は持っていない)。
- **`__ref_m` という名前のメソッド**は、まず同じ名前の宣言と照らす。
- **ライフタイムを固定するエイリアス** (`type S = &'static u8;`): ライフタイムを書かない使い方がどのエイリアスかは分から
  ないので、そうしたエイリアスがあるプログラムでは、以前と同じく辿らない。
- **要素を使わないクロージャの `map`** (`raw.iter().map(|_| "ok").collect()`) は、受け手が持つものを持たない。
- **`move` クロージャの中の同じ名前の束縛** (`let mut x = x;`) は捕捉を隠す。それへの代入は E0594 でない。
- **呼び出しが参照で返した受け手** (`id(&a).get()`) は、指す先を解放する一時値でない。
- **参照を通した `FnMut`** (`f: &F`): `*f` の `&mut` (E0596)。境界の引数の数と、引数のプリミティブ型も照らす。代わりの
  型のインスタンスでは、ほかの型エラーと同じく、そうしたエラーはその検査を止めるだけ。
- **`&&` / `||` の連鎖の途中で発散する項** (`a && { return true; } && false`): 前の項の値で連鎖の終わりに着く。以前は
  その終わりを閉じないまま下ろしていて、Cranelift が panic した。
