# リージョン (ライフタイム) 検査、その 42: Drop の検査でのトレイトのヘッダと等式の値、`let _` でのトレイトオブジェクトの引数の不変性

日付: 2026-11-28

その 41 ([2026-11-27-04](2026-11-27-04-region-check-41.md)) は #324 でマージした。この段階は、その 41 が挙げた穴の
うち 3 つを扱う: `Drop` の impl が守るべき規則 (E0367) の 2 つと、値が `let _` の注釈へ流れるところの 1 つである。

## 1. 加えたもの

- **トレイトが `?Sized` のパラメータを Sized にするのは、そのヘッダによってだけである。** `struct S<T: ?Sized +
  Tr>` での `impl<T: Tr> Drop for S<T>` (その T は Sized) は、Tr が `Sized` を導くのでない限り `T: Sized` を求める:
  E0367 である。その 41 は、トレイトのヘッダのテキストのどこかに `Sized`、`Clone`、`Copy`、`Default` の語があるかを
  見ていた。今はヘッダを構文解析し、その上位トレイトと `where Self: ..` の境界だけを数える:
  - 拒否する (rustc と同じく E0367): `trait Tr<U: ?Sized>`、`trait Tr<U: Clone>` (トレイト自身のパラメータの境界)、
    `trait Tr where u8: Clone` (別の型への境界)、`trait Tr: /* Default */ std::fmt::Debug` (コメント)。
  - 受理する: `trait Tr: Sized`、`trait Tr where Self: Sized`、`trait B: Clone` のときの `trait Tr: B`、`trait Tr:
    std::default::Default`。
- **境界の等式の値。** 定義が `T: Iterator<Item = u8>` と書くところの、impl の `T: Iterator<Item = u16>` は E0367
  である ("`Drop` impl requires `<T as Iterator>::Item == u16` but the struct it is implemented for does not")。
  その 41 が確かめていたのは、定義に同じ名前の等式があることだけだった。今は、impl のパラメータを定義のものに
  名前を変えたうえで、値を定義のものと比べる (`struct S<T: Iterator<Item = U>, U>` での `impl<A: Iterator<Item =
  B>, B> Drop for S<A, B>` は受理する)。self 型が持たないパラメータを名指す値は、これまでと同じく成り立ちうるので
  確かめない (`impl<T: Trait<Assoc = U>, U: ?Sized> Drop for Foo<T>`、dropck/constrained_by_assoc_type_equality.rs)。
- **`let _` でも、トレイトオブジェクトの引数は不変である。** `make() -> Box<dyn Foo<Bar = &'static u32>>` での `let
  _: Box<dyn Foo<Bar = &'a u32>> = make();` は `'a: 'static` を求める: rustc の "lifetime may not live long enough"
  である (variance/variance-associated-types2.rs)。名前の束縛 (`let x: ..`) は (型の不一致として) すでに拒否して
  いた。`let _` は、ライフタイムだけが違う型をリージョン検査に任せる。その検査は、トレイトオブジェクトに 1 つの
  リージョン (自分のもの) しか与えない。今は、値の型がトレイトオブジェクトの引数 (`dyn Foo<..>`、`dyn Fn(..)`) に
  書く `'static` が、注釈のその場所のライフタイムを `'static` にする。オブジェクト自身のライフタイム (`dyn Foo +
  'a`) はこれに入らない。注釈の省略されたライフタイム (`dyn Foo<Bar = &u32>`) は推論される。値の型の名前付きの
  ライフタイムは取らない: 呼ばれる関数のものかもしれない。

  呼ばれる関数のものかもしれないので、値の `'static` だけを取る。
