# rustc 自身の UI テストを仕様のテスト集にする

日付: 2026-11-18

rust-lang/rust の `tests/ui` は、Rust にとって実行できる仕様にいちばん近いもの。各ファイルが、頭の指示で、実行できる
べきか、検査を通るべきか、拒まれるべきか (期待するエラーは `//~ ERROR` で印を付ける) を書いている。
`bench/rust_ui.py` は zustc をそれに対して走らせ、通った割合を出す。

## 取り方

git submodule にすると rust-lang/rust 全体を取ってきてしまい、submodule を部分 checkout にするには手で設定が要る。
そこでスクリプトがコミット (タグ 1.100.0、`0ef1bc386`。ここで使っている rustc と同じコミット) を固定し、`tests/ui`
だけを、浅く・blob を絞った部分 clone で `out/rust-tests` に取る。6 秒、170 MB、テストのファイルは 20,364。

## 何を通ったとするか

各テストの種類は、rustc の compiletest と同じく指示から決める:

| 種類 | ファイル | 通ったとする条件 |
|---|---:|---|
| run-pass | 3771 | zustc がビルドでき、終了コード 0 で、`<名前>.run.stdout` があればそれと同じものを出す |
| check-pass | 3654 | `zustc check` が通す |
| build-pass | 572 | zustc がビルドできる |
| compile-fail (pass / fail の指示がない) | 11707 | `zustc check` が、注釈の指す行にエラーを出して拒む |

zustc に求められないものが要るテストは「対象外」に数える: nightly の `#![feature]`、補助のクレート
(`aux-build`・`aux-crate`)、`compile-flags` / `rustc-env`、`revisions`、Linux x86-64 以外のターゲット、
`ignore-test`、注釈のない compile-fail。zustc の 1 回の実行は、アドレス空間 2 GB (`prlimit`) と時間で制限する。
制限を付ける前は、1 つのテストがマシン全体のメモリを使い切った。

compile-fail は「拒んだ」だけでは当てにならなかった。最初の版はどんな拒み方でも数えて 64% になった。その多くは、
テストが確かめたいのとは関係のない理由 (見つからない型など) で拒んでいた。注釈の行 (`//~` はその行、`//~^` は
`^` 1 つにつき 1 行上、`//~|` は前の注釈と同じ行) にエラーを出すことを条件にすると 31%。ほかの行だけで拒んだものは
「行が違う」として別に数える。

## 結果

4 コア・3 並列で、対象のテストに 112 秒かかる。

| 種類 | 対象 | 通った | 失敗 | 行が違う | クラッシュ | 時間切れ | 通った割合 | 対象外 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| run-pass | 2413 | 1120 | 1287 | - | 5 | 1 | 46.42% | 1357 |
| check-pass | 1807 | 831 | 972 | - | 4 | 0 | 45.99% | 1843 |
| build-pass | 135 | 64 | 69 | - | 2 | 0 | 47.41% | 354 |
| compile-fail | 7358 | 2291 | 2613 | 2428 | 23 | 3 | 31.14% | 4438 |

同じマシンで 2 回走らせ、通ったテストの集合は同じだった。

## 後退させないために

`bench/rust_ui_passing.txt` は通った 4306 のテストの一覧。CI (`rust-ui` のジョブ) が `tests/ui` を取ってきて、一覧の
テストが通らなくなれば失敗する (時間切れは警告だけ)。変更で通るテストが増えたら、`--write-baseline` で一覧を
書き直す。ベンチマークのワークフローも、通った割合と数をダッシュボードに送る。

## 次にやること

失敗したものが言語の残りの仕事の一覧になる: `out/rust_ui_results.txt` にすべてのテストの結果があり、`--filter` で
1 つの分野に絞って走らせられる (例: `--filter tests/ui/closures`)。コンパイラはどんな入力でも panic するべきでは
ないので、34 件のクラッシュから先に直す。
