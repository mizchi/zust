# リージョン (ライフタイム) 検査、その 5: 型パラメータのリージョン (issue #1)

日付: 2026-11-22

その 4 ([2026-11-21-07](2026-11-21-07-region-check-4.md)) は、何も呼ばないジェネリック関数を、型パラメータごとの代わりの
型で検査する。その代わりの型はリージョンを持たなかった。そのため `T: 'a` は何の意味も持たず、E0310 / E0309 のテスト
(「the parameter type `T` may not live long enough」) は落ちようがなかった。この段は、代わりの型にリージョンを持たせる。

## 1. 加えたもの

- **代わりの型のリージョン:** 代わりの型はリージョンを 1 つ持ち、共変。パラメータの値が借りうるものを表す。
  インスタンスの中では universal なリージョンで、名前は代わりの型と同じ (`T#`)。パラメータの `T: 'a` / `T: 'static`
  の境界が名指すものと、引数の型が導くもの (`&'a T` は `T: 'a` を導く) より長生きする。
- **エラー:** 代わりの型のリージョンが、ほかのリージョンより長生きする必要があれば「the parameter type `T` may not
  live long enough」。'static に対してなら E0310、それ以外なら E0309。
  - 例: `T` が `T: 'a` を持たない関数の中の、`fn outlives<'a, T: 'a>(..)` への呼び出し `outlives(cell, t)`。
  - 例: `Box<dyn X + 'static>` として返す `Box::new(v)`。
- **よく通る経路のコスト:** `lts_of` は、代わりの型を作ったあとでだけ代わりの型を見る (atomic のフラグ)。それまでは
  struct の表のロックを取らない。
- **トレイトの境界:** 型パラメータがトレイトで縛られた関数も、本体がそのトレイトの宣言するメソッドを 1 つも呼ばなければ、
  代わりの型のインスタンスを作る (`Box::new(v)` を `Box<dyn X>` へ)。
  - それらのメソッドの呼び出しで検査できるのはトレイトの宣言だけで、コストはその型検査にかかる。patterns の入力では、
    そうした関数 4 つで +0.5% だった。
  - 代わりの型のメソッドは、境界のトレイトの宣言に解決する。モジュールの中のトレイトは、パスの最後の名前で引く。
  - 本体のないトレイトのメソッドも、代わりの型の `Self` については呼べる (そのインスタンスはコンパイルしない)。
- **unsize のキャスト:** `Box::new(v) as Box<dyn Tr + 'static>` は型の変換で、値は書いた型へ流れる。
- **`dyn Tr + '_`:** シグネチャの中では省略したライフタイムで、呼び出しごとに新しいものになる。既定のライフタイム
  (`Box<dyn Tr>` なら 'static) ではない。その `'_` だけを書くシグネチャは、リージョンを持たないものとして読まれて
  いた。そのため `fn get_v(gc: Box<dyn G + '_>)` に対する `get_v(Box::new(h) as Box<dyn G>)` を拒否していた。
- **E0594 などの借用のエラー (#40 のレビュー):** lowering が自分で返す借用の種類のエラーは、代わりの型のインスタンスでも
  報告する。HashMap の `m[&k] = v` の E0594、`cannot borrow`、E0596、E0384 がそれにあたる。型検査のエラーと一緒に
  捨てない。

## 4. まだ扱わないもの

- **射影型:** 型パラメータの射影型のリージョン (`<T as Tr>::Output: 'a`)。代わりの型は関連型を持たないので、そうした
  関数は検査しない (`nll/ty-outlives/projection-*`)。
- **`impl Trait` の結果:** `impl Trait` の結果が捕捉するリージョン (`type_parameters_captured`)。
- **async fn:** async fn の代わりの型のインスタンス。
