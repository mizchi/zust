# リージョン (ライフタイム) 検査、その 18: コンストラクタを通した let の延長、クロージャのキャプチャの再借用、トレイトオブジェクトの drop、値としてムーブされる `&mut`、腕ごとの scrutinee の drop (issue #1)

日付: 2026-11-23

その 17 ([2026-11-23-06](2026-11-23-06-region-check-17.md)) は #97 でマージした。この段階で加えるもの:

- `let` がコンストラクタやリテラルを通して延長する一時値 (rustc 1.79 から);
- 関数ポインタを通した呼び出し。その結果は引数が借用するものを持つ;
- クロージャのキャプチャの再借用。クロージャの環境で抑えられる;
- 借用するものを drop が使うトレイトオブジェクト;
- 強制変換が再借用しないところで値としてムーブされる `&mut` 参照;
- 値全体を取らない腕で保たれる scrutinee の drop。

借用検査の前でテストを止めていた誤ったエラーも直す:

- `vec![&mut x]`;
- `let f: fn(_) -> _ = foo;`;
- トレイトを実装する参照から作ったトレイトオブジェクト。

その 17 のレビューが残した 3 つの指摘 (そのレポートの第 5 節) のうち 2 つを、ここで扱う。

## 1. 加えたもの

### 直した誤ったエラー

- **数のローカルの `vec![&mut x]`** は「internal: borrowed local is not in memory」だった
  (span/regions-escape-loop-via-vec.rs がそこで止まっていた)。アドレスを取られるローカルを探す走査が、マクロの引数の `&`
  を、値を読む整形マクロのものとして読んでいた。今はそう読むのは整形マクロのものだけである。
- **`let f: fn(_) -> _ = foo;`** は「mismatched types: expected `fn(_) -> _`」だった: 関数ポインタの注釈の穴を見ていなかった。
  リージョン検査はそういうローカルに木を与えなかったので、それを通した呼び出しを追わなかった。今はその領域は、初期化式が
  流れ込む新しいものである。`foo<'a>(&'a u32) -> &'a u32` の `f(x)` を `&'static` として返すと「lifetime may not live long
  enough」になる (nll/mir_check_cast_reify.rs、mir_check_cast_unsafe_fn.rs)。
- **`impl<'a> Foo for &'a isize`** で `&isize` から作った `Box<dyn Foo>` は「no implementation」だった。今のディスパッチは、
  参照への impl のメソッド (参照先の型の `__ref_m`) を引く。tests/acg/dyn_of_ref_impl.rs が出力を rustc のものと比べる。

### 借用検査

- **`let` は、初期化式の延長する式の中の一時値の `&` を延長する:**
  - タプル struct やバリアントのコンストラクタの引数;
  - タプル、配列、struct リテラルのフィールド。

  後で使う `let x = Some(&[name]);` は誤った E0716 だった (borrowck/array-slice-coercion-mismatch-15783.rs がそこで止まって
  いた)。関数の呼び出しとメソッドの受け手は延長しない: 後で使う `let h = Some(temp().as_str());` は今も E0716 である。
- **関数ポインタを通した呼び出しは、引数が借用するものを持つ** (結果が参照を持つとき)。後で使う
  `let f = id::<&String>; let g = f(&temp());` は E0716 である。
- **クロージャの本体で再借用したキャプチャは、クロージャの環境で抑えられる。** `data: &'static mut ()` の `|| doit(data)` を
  `&'static mut ()` が期待されるところに渡すのを受け入れていた (nll/issue-42574-diagnostic-in-nested-closure.rs)。環境は
  呼び出しの間だけクロージャのものなので、再借用が `'static` より長生きするのは「lifetime may not live long enough」である。
  先にムーブしたキャプチャ、コピーした共有参照、どんなライフタイムでも取る呼び出し先は問題ない。
- **unsized なフィールドを持つ struct のコンストラクタを値として使うと E0277 である。** `struct Test([i32]);` の
  `let _x: fn(_) -> Test = Test;` (unsized-locals/issue-30276.rs)。コンストラクタの値は `|a0| Test(a0)` と書かれ、サイズの
  分からない型のクロージャのパラメータは、rustc が報告するとおりコンストラクタで E0277 になる。注釈の穴を型付けした (上) ことで
  ここに届くようになった。
- **scrutinee の drop は、値全体を取らない腕で保たれる。**
  `match heap.peek_mut() { x if flag => drop(x), _ => heap.push(1) }` を受け入れていた (rustc では E0499; その 17 の
  レビュー)。値全体を束縛する腕が 1 つあると、どの腕からも scrutinee の drop が外れていた。今は値を取る腕はそれをムーブし、
  その道ではその drop は何も持たない。ほかの腕は文の終わりまでそれを保つ。
- **型を書かない `let` の初期化式で値として読む `&mut` はムーブされる。** これらを受け入れていた (その 17 のレビュー):
  - `a: [&mut i32; 1]` の `let b = a[0];` (E0508);
  - `p: *const &mut i32` の `let y = unsafe { *p };` (E0507);
  - `qq: &mut &mut i32` の `let u = *qq;` (E0507)。

  借用検査は、強制変換のところの再借用のために `&mut` を `Copy` として扱い、型推論は `let` にその型を期待として渡す。型を
  書かない `let` の初期化式は強制変換のところではない。そこで (括弧とブロックの末尾を通して) 場所から値として読むものは、今は
  ムーブされる。引数と `let c: &mut i32 = a[0];` は今も再借用する。
- **トレイトオブジェクトの drop は、それが借用するものを使う。** rustc は `dyn` 型の drop が何をするか知らないので、
  オブジェクトが借用するものすべてを使うとみなす。これらを受け入れていた:
  - `let mut f: Box<dyn FnMut()> = Box::new(|| v += 1); f(); println!("{}", v);` (E0502: 借用は f の drop で使われる);
  - x が内側のブロックにある `blah = Box::new(&x) as Box<dyn Foo>;` (E0597、span/regions-close-over-borrowed-ref-in-obj.rs
    のケース)。

  `&dyn Trait` は何も持たないので、影響しない。

## 5. まだ扱わないもの

- **関数ポインタ型が領域を束縛するところに渡す関数アイテム** (`type G = for<'cx> fn(&'cx S) -> &'static S` と
  `fn baz(x: &S) -> &S` の `want_G(baz)`、rustc では E0308; regions/regions-fn-subtyping-return-static-fail.rs)。そういう型が
  束縛する領域はそれぞれの変数で、型エイリアスの領域は追わない。パラメータに書かれた型についての最初の部分は、次の段階のために
  進めている。
- **`let` の初期化式以外で値としてムーブされる `&mut`**: ジェネリックな f の `f(a[0])`、`vec![a[0]]` (E0508)。強制変換の
  ところでないとみなすのは、型を書かない `let` だけである。
- **impl のライフタイムを持つ関連定数の型** (`const C: &'a u32` の `<Foo<'a>>::C` を `&'static` として返す、
  nll/user-annotations/constant-in-expr-inherent-1.rs)。
- その 17 から:
  - 1 つの場所に書いたプログラムの 2 つの deref (`(&mut **w).bump()`);
  - `'static` の型引数を持つタプル struct のコンストラクタを値として使うもの;
  - ある型への impl があいまいなトレイト (borrowck/mut-borrow-in-loop-2.rs)。
- その 16 から:
  - ジェネリックな関数の `dyn Tr<T>`;
  - `&*vec![1].iter().next().unwrap()`;
  - opaque 型の member constraint (E0700);
  - タプルの推論の中の `&mut`;
  - フィールドごとの領域;
  - バリアントの `use … as S`;
  - `static` クロージャの借用検査。
