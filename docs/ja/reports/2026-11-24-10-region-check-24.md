# リージョン (ライフタイム) 検査、その 24: ジェネリックな関数の型での構造体の 'static 境界、参照による既定の束縛モードの下の `mut` 束縛、射影が選ぶ impl の outlives (issue #1)

日付: 2026-11-24

その 23 ([2026-11-24-09](2026-11-24-09-region-check-23.md)) は #126 でマージされた。この段階で加えるもの:

- 何も呼ばないジェネリックな関数が書く型に求める、構造体の `T: 'static` 境界;
- エディション 2024 より前の、既定の束縛モードが参照によるときの `mut` 束縛;
- 射影が選ぶ impl のヘッダーが、その impl のライフタイムについて宣言する outlives。

## 1. 加えたもの

- **ジェネリックな関数の型での、構造体の `T: 'static` 境界。** `struct Static<T: 'static>(T)` があるとき、`fn a<T>()` の中の
  `let _ = None::<Static<T>>;` を受理していた (rustc では E0310、regions/wf-bound-region-in-local-issue-115175.rs)。
  `let _: Option<Static<T>> = None;` と `Vec::<Static<T>>::new()` も同じだった。足りないものが 3 つあった:
  - ADT の `T: 'static` 境界を ADT 自身のライフタイムの中から探していたので、何も求めていなかった;
  - 何も呼ばないジェネリックな関数をプレースホルダーで検査するとき、シグネチャがライフタイムを指さなければリージョン検査が
    止まっていた;
  - 式の中のパスが書く型引数 (`None::<Static<T>>`) を、well-formed か確かめていなかった。

  今はどれもする。パスの型引数を確かめるのは、そういう構造体を含む型だけである: ほかの要求はパラメータの射影を通して
  成り立つことがあり、検査はそれを辿らない (implied-bounds/normalization.rs)。
- **既定の束縛モードが参照によるときの `mut x`。** エディション 2024 より前では、束縛の `mut` はモードを値によるものに
  戻す。`Copy` でない型のタプルで `for (n, mut m) in &tups {}` を受理していた (rustc では E0507、
  rfc-2005-default-binding-mode/for.rs)。`let (_, mut m) = &(1u8, 2u8); m += 1;` は誤った「expected `&u8`」だった。
  今はそういう束縛が、照合を通した参照から値を move する: 値が `Copy` でなければエラー、`Copy` ならその値の型になる。
- **射影が選ぶ impl の outlives。** `impl<'a, 'd: 'a> Visitor<'d> for &'a ()` があるとき、`fn visit_seq<'d, 'a: 'd>() ->
  <&'a () as Visitor<'d>>::Value {}` を受理していた (rustc では「lifetime may not live long enough」、
  nll/normalization-bounds-error.rs)。パラメータの型や `let` の型としてのそういう射影も同じだった。
  - サマリーは、impl のヘッダーがそのライフタイムについて `'d: 'a` を宣言するときにも、その impl の関連型の符号を持つ。
    値がライフタイムを指さないとき (`type Value = ()`) でもそうする。その outlives と、impl のトレイトパスが引数として書く
    ライフタイムも持つ。
  - 結果の型、パラメータの型、`let` の型として書いた射影は、それらを impl のライフタイムに求める。impl のライフタイムは、
    書いた self 型の、impl の self 型が持つ位置の部分と、書いたトレイトパスのライフタイム (`Visitor<'d>` の `'d`) である。
    パスが省略したものは新しい領域になる。
  - 関数に `where 'd: 'a` があるとき、またはそれを満たす `'static` のとき、射影は rustc と同じく受理する。
  - 関数のキャッシュのキーは、今は impl のヘッダーも持つ: 射影が impl を選ぶところでその outlives を求めるからである。
