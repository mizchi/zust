# リージョン (ライフタイム) 検査、その 8: `&mut` を通した書き込み、ムーブできないものからのムーブ、チューニング (issue #1)

日付: 2026-11-22

その 7 ([2026-11-22-03](2026-11-22-03-region-check-7.md)) は #46 でマージした。この段は、tests/ui で受け入れてしまう、
または違う場所で報告していた借用検査の場合を扱い、検査を安くする。

## 1. 加えたもの

### 借用検査

- **`&mut` を通した書き込み:** ローカルが持つ `&mut` を通して代入したものは、その指す先が持つ。
  - `let q = &mut p; *q = &y;` なら、p が y の貸し出しを持つ。y がなくなった後で p を使えば、`&y` で E0597。
  - 場所が持つ deref の数だけ深く辿る (`**r = ..`)。
  - 引数の後ろを指す `&mut` (`let q = &mut *x;`) を通したものは、関数より長く残るところにしまう。
  - 以前は q だけが貸し出しを持っていたので、y の後で p を使っても受け入れていた。
- **型パラメータに渡す `&mut`:** `fn generic<T>(x: T)` に対する `generic(self)` (`self: &mut X`) は型強制の場所でない
  ので、`self` は再借用でなくムーブされる。その後で使えば E0382。
  - 引数の型が `&mut` なら、これまでどおり再借用する。
- **ムーブできないものからのムーブ:**
  - `Drop` を実装した型の値からは、フィールドをムーブできない (E0509): `s.f`、`S { a: 2, ..s }`、そうしたフィールドを
    値で束縛するパターン (`let S { f } = s;`、match の腕、引数のパターン)。
  - static からもムーブできない (E0507): `static BAR: Foo` に対する `test(BAR)`。定数は使うたびに新しい値。
- **union の 2 つのフィールドは同じメモリ:** `&mut u.s.a` と `&u.z.c` はぶつかる (E0502)。同じフィールドのフィールド
  (`u.s.a`、`u.s.b`) はぶつからない。
- **実行時の値のタプル・配列・struct のリテラルは一時値:** ローカル v の `gimme(&(v,))` は、`&(1, 2)` のように static
  へ昇格しない。文の後で使う借用なら E0716。
- **書式文字列の `{x}` を報告する場所:** `println!("{x}")` が名指す変数は、書式文字列の位置を持つ。そこで初期化されて
  いない x を使えば (E0381)、以前は関数の最初の行で報告していた。

### シグネチャ

- **E0582:** `for<'a>` の束縛子のライフタイムを、境界の結果だけが名指す (`F: for<'a> Fn() -> Option<&'a i32>`) か、
  関連型の束縛だけが名指す (`for<'a> Iterator<Item = &'a i32>`)。そうした境界を満たす型はない。束縛子を持つ述語の
  `:` の前の型は入力 (`for<'a> &'a T: IntoIterator<Item = &'a U>`)。ジェネリックな関連型の束縛 (`Item<'a> = &'a T`)
  は検査しない。構文解析がその引数を捨てていて、引数がそのライフタイムを名指すことがある。

### レビューの後

- **別のフィールドを借用中の union のフィールドへの書き込み** (`&u.a` が生きているときの `u.b.x = 2`) は E0506。以前は
  パニックしていた。2 つのパスが接頭辞を共有するかの判定が union の 2 つのフィールドを 1 つとみなし、書き込みの検査が
  貸し出しのパスを末尾より先で切っていた。union の 2 つのフィールドは別の場合として扱う。1 つのフィールドへの書き込みは
  これまでどおり union 全体を初期化するので、先にムーブしたフィールドをまた使える (nll/issue-55651.rs)。
- **フィールドの `&mut` を通した書き込み** (`q = (&mut p, &mut z)` での `*q.0 = &y`) は辿らない。ローカルの貸し出しは
  フィールドごとに持たないので、q.0 がどれを持つかは分からない。辿ると z も y の貸し出しを持つことになっていた。
- **より深い E0509:** `Drop` を実装した型のフィールドの下で値を束縛するパターン (`D { f: Some(x) }`) と、そうした
  フィールドに対する match (`match d.f { Some(x) => .. }`)。
- **型パラメータに渡すフィールドの `&mut`** (`consume(s.0)`) は、`&mut` のローカルと同じくムーブされる。
- **モジュールのパスで static からムーブ** (`take(m::BAR)`) すると E0507。値で渡す引数だけを調べる。パスは場所の式で
  ないので、ムーブしないところでも値として読む (`m::KEY.with(..)`)。

## 5. まだ扱わないもの

- **呼び出しが、渡された `&mut` を通してしまうもの:** `invoke(self)` が `*self.p = self.y` と書く `s.invoke()`
  (nll/capture-ref-in-struct.rs)。書き込みは別の関数の中にあり、それを伝えるのはシグネチャのリージョンだけ。
- **型パラメータにトレイトの境界を持つジェネリックな関数 (`K: Clone`):** そうした関数には代わりの型のインスタンスが
  なく、本体を検査しない。
