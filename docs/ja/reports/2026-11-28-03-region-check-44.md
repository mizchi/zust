# リージョン (ライフタイム) 検査、その 44: placeholder の universe と outlives、トレイトの義務での fn ポインタの型の束縛 (高階のトレイト境界、2)

日付: 2026-11-28

その 43 ([2026-11-28-02](2026-11-28-02-region-check-43.md)) は #350 でマージした: プログラムの impl を選ぶ呼び出しの
境界は、impl のヘッダを目標と結び、境界が束縛するライフタイム (`for<'a>`) は呼び出しの placeholder である。
placeholder は、ほかと関係を持たない普遍リージョンだった。そのため、検査が一般性の足りない impl を見つけたのは、
placeholder が別の普遍リージョンか `'static` でなければならないところだけだった。この段階は、普遍リージョンには
ない、placeholder が守る規則と、fn ポインタの型の束縛を扱う。

## 1. 加えたもの

- **universe。** placeholder は、その義務より前に作られたリージョンが名指せない universe のものである: 呼び出し
  側が持っていた目標の型のリージョン (推論の変数も) は、それであってはならない。`T: for<'a> Foo<&'a isize>` と
  `impl<'a> Foo<&'a isize> for &'a u32` での `want_hrtb::<&u32>()` は、参照のリージョンを placeholder にする: rustc と
  同じく "not general enough" である。その 43 がこれを見つけたのは、そのリージョンが呼び出し側の名前付きの
  ライフタイムであるときだけだった。
- **placeholder はそれ自身だけを outlive する。** placeholder は本体の点を含まない (rustc の
  `check_bound_universal_region`): 等しくないリージョンを outlive しなければならない placeholder は "not general
  enough" である。`F: for<'b> Foo<'b>` に対する `impl<'a, 'b: 'a> Foo<'b> for FooS<'a>` での `test::<FooS>(..)`
  (higher-ranked/trait-bounds/due-to-where-clause.rs): placeholder の `'b` は FooS のリージョンを outlive しなければ
  ならない。リージョンが placeholder を outlive しなければならないことは扱わない: 外側の universe のそれは
  'static でありうる。
- **fn ポインタの型の束縛。** 目標の fn ポインタの型が束縛するリージョンは、impl のリージョンのどれでもない。
  ただし、その場所で impl のヘッダも束縛するものは別である: `impl<'a> X for fn(&'a ())` と `impl<A> Foo for fn(A)`
  は、`for<'r> fn(&'r ..)` である `fn(&())` / `fn(&i32)` には一般性が足りない。目標が名指すリージョン (呼び出し先の
  ライフタイム、`'static`、placeholder) も、ヘッダが束縛するものではない: `impl X for fn(&())` は `fn(&'a ())` の
  impl ではない。そうしたリージョンが分かるのは 2 か所である:
  - fn ポインタの型で書いた型引数 (`indirect::<fn(&())>()`): そのリージョンは、その型が束縛するものである;
  - 境界の引数 (`T: Trait<for<'b> fn(fn(&'b u32))>`): 境界が書くコード。

  推論が作ったリージョンはどちらでもありうるので、取らない。impl の型パラメータを中に持つ fn ポインタの型を
  持つヘッダ (`impl<A> Foo for fn(A)`) は、今は結ぶべきリージョンを持つ (TraitDb::lt_traits)。
