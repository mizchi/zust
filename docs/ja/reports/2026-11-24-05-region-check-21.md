# リージョン (ライフタイム) 検査、その 21: 関数ポインタに強制する関数アイテム、共有参照を通した deref 強制、注釈付きの `let` の `ref mut` 束縛 (issue #1)

日付: 2026-11-24

その 20 ([2026-11-24-04](2026-11-24-04-region-check-20.md)) は #111 でマージした。この段階で加えるもの:

- 注釈の関数ポインタ型に強制するところでの、関数アイテムのシグネチャの well-formedness;
- 共有参照を通した deref 強制の領域。main にもある誤ったエラーがなくなる;
- 型を書いた `let` での場所の `ref mut` 束縛。その場所を両向きにその型にする。

## 1. 加えたもの

- **注釈の関数ポインタ型に強制する関数アイテム: そのシグネチャの型は well-formed である。**
  `fn foo<'a, 'b, T>(_: &'a &'b (), v: &'b T) -> &'a T` で `let f: fn(_, &'a T) -> &'static T = foo;` を受け入れていた
  (rustc では「lifetime may not live long enough」): `&'a &'b ()` は `'b: 'a` を求めるので、`'a` は `'static` より長生き
  しなければならなかった (implied-bounds/implied-bounds-on-nested-references-plus-variance.rs、-early-bound.rs)。そのため:
  - 強制するところで、アイテムのシグネチャの型を well-formed とする;
  - ジェネリックなアイテムの型引数を注釈から解く (前はそのインスタンスの木が分からなかった);
  - 穴のある関数ポインタの注釈 (`fn(_, &'a T) -> &'static T`) は、ほかの部分が書く領域を保つ: 穴の領域は新しく、残りは
    書いたとおりである。前は、穴が 1 つでもあれば注釈の全体が新しい領域だった。

  関数ポインタ型が領域を束縛するところ (`fn(_, &'a T, &())`) ではしない: rustc はそれを受け入れる。既知のバグである
  (#25860、check-pass のテスト implied-bounds-on-nested-references-plus-variance-2.rs)。
- **共有参照を通した deref 強制は、内側の参照が持つものを持つ。** 次のものは main でも誤ったエラーだった (rustc は
  受け入れる):
  - `parts: Vec<&'a str>` をローカルとして、`Option<&'a str>` として返す `if let [commit, ..] = &parts[..] { Some(commit) }`:
    E0515;
  - `&'a str` として返すローカル `c: &&'a str`: E0515;
  - `fn h<'a, 'b>(x: &'a &'b u32) -> &'b u32 { x }` と `fn f<'a>(x: &'a mut &'static u32) -> &'static u32 { x }`:
    「lifetime may not live long enough」。

  強制は再借用 `&**c` である。それは、通る参照より長生きしない。内側から外へ向かって、共有参照がそこで止める (NLL の再借用の
  制約): `&'1 &'a str` では `'a` だけである。今はリージョン検査の流れがそれに従う。借用検査は、そういうローカルを返すとき、
  または内側の型を取るフィールドのコンストラクタに渡すとき、`let` や引数のところと同じく内側の参照をコピーして取り出す。
  そのために、`Vec` / `VecDeque` の要素は要素の型の場所である。borrowck/cannot-return-ref-to-fn-param-in-filter-map.rs
  には、もう 16 行目の誤ったエラーはない。期待するエラー (6 行目、クロージャの `ref` パラメータ) はまだ報告しない。
- **注釈付きの `let` での場所の `ref mut` 束縛は、両向きに注釈の型である。** `x: Foo<fn(&'a str)>` で
  `let Foo(ref mut y): Foo<fn(&'static str)> = x;` を受け入れていた (rustc では「lifetime may not live long enough」、
  mir/field-projection-mutating-context2.rs): y は `x.0` の `&mut` で、`&mut` は不変なので、場所の型は注釈の型でなければ
  ならず、それは `'a: 'static` を求める。パターンが `ref mut` で束縛し、初期化式が場所であるところでは、注釈の木が場所の
  木へ流れ戻る。このテストの `(x.0)(&string)` での誤ったエラー (deref 強制) は、上の項目でなくなった。

## 5. まだ扱わないもの

- **パラメータや注釈の型としての、射影を正規化した型** (`type Ty = &'static T` のもとで `'a: 'static` を含意する
  `_wf: <&'a u8 as Tr>::Ty`、implied-bounds/assoc-ty-wf-used-to-get-assoc-ty.rs、ここでは 16 行目の誤ったエラー;
  `let _: <() as Foo>::Out = &a;`、nll/user-annotations/normalization.rs)。要約は impl の関連型のコードを持たない。
- **ローカルに入れてから関数ポインタ型にキャストするクロージャ** (`let c = |_: &'static u32| {}; c as fn(&u32)`、
  rustc では E0308): キャストからはクロージャのパラメータが見えない (その 20 の第 4 節)。
- **結果が抜け出す領域のあいだ借用される、クロージャの `ref` パラメータ** (`.filter_map(|ref line|
  self.make_entry(line))`、borrowck/cannot-return-ref-to-fn-param-in-filter-map.rs の 6 行目)。
- **ライフタイムを固定する関数ポインタ型の型エイリアスを通して渡す関数アイテム**: `type G = for<'cx> fn(&'cx S) ->
  &'static S;` の `want_G(baz)` (regions/regions-fn-subtyping-return-static-fail.rs)。要約はエイリアスの定義の
  ライフタイムを持たず、関数の要約はそのモジュールのエイリアスを見ない。
- **関数ポインタ型の別々の束縛ライフタイム** (`for<'a, 'b> fn(&'a u32, &'b u32) -> &'a u32`) は、関数アイテムを渡す
  ところで 1 つのプレースホルダーになる: 領域のコードは束縛を持たない (その 19 の第 4 節)。
- **関数で作り、別のクロージャの本体で呼ぶクロージャ** (adt-tuple-struct-calls.rs の
  `annot_reference_named_lifetime_across_closure`)。内側の本体は、外側のクロージャのシグネチャなしで単独に検査する。
- **struct のフィールドを通して、または別のクロージャの本体で呼ぶクロージャの、呼び出しが借用するもの**
  (closures/issue-113087.rs)。持つのは、ローカルの名前で呼ぶクロージャだけである。
- **使われない定数の初期化式** (main の中の `const z: &'static isize = { let p = 3; &p };`、static/issue-18118.rs) と、
  定数の初期化式のブロックの中の関数アイテム (borrowck/borrowck-fn-in-const-c.rs)。定数は使うところで展開して検査する。
- **型がトレイトのライフタイムを指すトレイトの定数** (`<T as Foo<'a>>::C`、`T: Foo<'a>` の `T::C`、
  nll/user-annotations/constant-in-expr-trait-item-2.rs、-3.rs)。何も呼ばないジェネリックな関数は、定数を使うところに
  届かない。
- **ガードの一時値を通して読む `&mut` の暗黙の再借用** (後で使う `let val: &_ = x.borrow().0;`、
  borrowck/issue-36082.rs)。
- **スライスでも `str` でもない型の `Cow<'_, T>`**、関数の中の `use std::option::Option::Some as S;`
  (lifetimes/temporary-lifetime-extension-tuple-ctor.rs)。
- **`let` の初期化式以外で値としてムーブされる `&mut`**: ジェネリックな f の `f(a[0])`、`vec![a[0]]` (E0508)。
- その 17 から:
  - 1 か所に書いたプログラムの 2 つの deref (`(&mut **w).bump()`);
  - ある型への impl があいまいなトレイト (borrowck/mut-borrow-in-loop-2.rs)。
- その 16 から:
  - ジェネリックな関数の `dyn Tr<T>`;
  - `&*vec![1].iter().next().unwrap()`;
  - opaque 型のメンバー制約 (E0700);
  - タプルの推論の中の `&mut`;
  - フィールドごとの領域;
  - `static` クロージャの借用検査。
