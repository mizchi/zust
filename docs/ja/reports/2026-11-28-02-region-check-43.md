# リージョン (ライフタイム) 検査、その 43: 呼び出しのトレイトの義務と、その束縛の placeholder (高階のトレイト境界、1)

日付: 2026-11-28

その 42 ([2026-11-28-01](2026-11-28-01-region-check-42.md)) は #342 でマージした。この段階から、高階のトレイト境界
(`for<'a> T: Foo<&'a isize>`) を扱う。zustc はこれを何も読んでいなかった: パーサは `for<'a>` を捨て、トレイトの
解決器は型だけで impl を選ぶ (`Ty` はリージョンを持たない)。そのため、一部のライフタイムでしか成り立たない impl が
満たす境界を受理していた。`for<'a>` を書く tests/ui のテストの 417 件のうち 151 件が通らず、その compile-fail の
うち 16 件が "implementation of `X` is not general enough" である。

## 1. 設計

`Ty` はリージョンを持たないままにする: コード生成、単相化、型の検査はリージョンなしで型を比べる。リージョンを
持つ型は、型の数も作業も至るところで増やす。リージョンは、リージョン検査がすでに持っているところに置く: 値の
リージョンの木と、シグネチャが書くものについての、型のリージョンのスロットの上のコードである。rustc もこうして
いる: トレイトの選択はライフタイムを決めず、リージョンの制約を出し、借用検査がそれを placeholder とともに解く。

そこで、トレイトの義務を呼び出し側のリージョン検査で確かめる:

- **impl は型で選ぶ。** 呼び出し先の、プログラムのトレイトへの境界は、型で impl を選ぶ (`TraitDb::select`: ヘッダが
  合い、where 句が成り立ち、すべて読めた impl がちょうど 1 つ)。
- **そのヘッダのリージョンは目標のものである。** impl のヘッダは目標の型であり、2 つのリージョンは等しい: self 型
  のもの (呼び出しの型引数の木)、トレイトの型引数のもの (境界が書くとおり、呼び出しでの呼び出し先のライフタイム
  で)、そのライフタイム引数のもの。impl のライフタイムは義務の新しい変数であり、そのヘッダの `'b: 'a` はそれらに
  ついて成り立たなければならない。`Summary::impl_head` が、ライフタイムを名指すヘッダのコード (その self 型、
  トレイトの引数、宣言された outlives) を持つ。
- **束縛のライフタイムは placeholder である。** 境界が名指し、呼び出し先のものでないライフタイムは、境界自身のもの
  (`for<'a>`) である: 呼び出しの placeholder、つまり、それ自身と `'static` だけが outlive する普遍リージョンである。
  それであり、かつ `'static`、呼び出し側のライフタイム、別の placeholder でもなければならない impl のリージョンは、
  2 つの普遍リージョンを互いに outlive させる。検査はそれを報告する。ここでは rustc の "implementation of `Foo` is
  not general enough" として。
- **入れ子の義務。** そうしたトレイトについての impl の where 句は、次に impl のライフタイムの義務になる (`impl<T>
  DeserializeOwned for T where T: for<'de> Deserialize<'de>`)。
- **汎用関数のインスタンスでは作らない。** rustc は、汎用関数の本体の呼び出しの境界を、型パラメータが何であれ、
  本体の where 句から一度だけ示す: インスタンスの型の impl は、そこでは証明にならない。最初の版はインスタンスでも
  義務を作り、サイクルが check-pass のテストの誤ったエラーを見つけた
  (implied-bounds/implied-bounds-on-trait-hierarchy-2.rs。その where 句 `S: for<'a, 'b> Subtrait<'a, 'b, &'b &'a ()>` が
  `S: for<'a, 'b> Supertrait<'a, 'b>` を与えるところで、`MyStruct` の impl は `'a: 'b` を求める)。

義務を作るのは、ある impl が結ぶべきリージョンを持つトレイトへの境界だけである (`TraitDb::lt_traits`: ライフタイム
(`'static` も) を名指すか、fn ポインタの型でライフタイムを束縛するか、outlives を宣言する impl のヘッダと、その
ような where 句を impl が持つトレイト)。それらのないプログラムは、この何もしない。そうでなければ、呼び出しは
呼び出し先の境界をその集合で引く。

## 2. 加えたもの

- **"implementation of `Foo` is not general enough"。**
  - `impl Foo<&'static isize> for StaticInt` での `T: for<'a> Foo<&'a isize>`、または `impl<'a> Foo<&'a isize> for &'a u32`
    と `T = &'a u32` (呼び出し側の `'a`) でのそれ。
  - `impl<'a> Foo<(&'a isize, &'a isize)> for SomeStruct` での `T: for<'a, 'b> Foo<(&'a isize, &'b isize)>`。
  - `impl Bar<'static> for u16` での `T: for<'q> Bar<'q>`。
  - `impl<T> DeserializeOwned for T where T: for<'de> Deserialize<'de>` と `impl<'de: 'a, 'a> Deserialize<'de> for &'a str`
    を通した、`T = &'static str` での `T: DeserializeOwned`。
- **束縛のない同じ関係。** `impl Foo<&'static isize> for St` での、呼び出し先の `'a` の `T: Foo<&'a isize>` は、呼び出し
  で `'a` を 'static にする: ローカルの `x` の `want_a::<St>(&x)` は、rustc と同じく E0597 である。
- **シグネチャにリージョンのない関数のリージョン検査**を、そうした義務のある呼び出しで始める (`fn give_static() {
  want_hrtb::<StaticInt>() }`)。
- **境界のタプルの引数** (`Foo<(&'a isize, &'b isize)>`): 解決器の読み方では `Fn(..)` のものとされるが、義務のために
  読む。

## 5. まだ扱っていないもの

高階のトレイト境界の、次の段階:

- **placeholder と等しい外側の universe のリージョン。** 呼び出しの前から目標が持っていたリージョン
  (`want_hrtb::<&u32>()`、その省略されたライフタイムは推論の変数である) は placeholder であってはならない: rustc の
  universe である。ここではそうでありうるので、受理する (rustc の "not general enough")。
- **別のリージョンを outlive しなければならない placeholder** (`F: for<'b> Foo<'b>` に対する `impl<'a, 'b: 'a> Foo<'b> for
  FooS<'a>`、higher-ranked/trait-bounds/due-to-where-clause.rs): placeholder は本体の点を含められない (rustc の
  `check_bound_universal_region`)。ここでは受理する。
- **fn ポインタの型の束縛。** `impl<'a> NotHR for fn(&'a ())` と `fn(&())` (高階)、または `impl<A> Foo for fn(A)` と
  `fn(&i32)` (hr-fn-ptr-trait-impl-mismatch-29061.rs、hrtb-fn-ptr-impl-not-general-enough-57936.rs、issue-46989.rs): 木は、
  fn ポインタの型が束縛するリージョンとそうでないものを区別しない。型の中で入れ子になった束縛も区別しない
  (hrtb-exists-forall-trait-*.rs)。
- **高階の型の部分型** ("one type is more general than the other"、E0308) と、境界が高階のクロージャ
  (hrtb-perfect-forwarding.rs)。
- **汎用関数の本体の義務** (その where 句から、つまり placeholder の環境から) と、汎用関数のインスタンスの義務:
  作らない。
- **型パラメータ以外への where 句** (`for<'a> &'a T: Bar`)、**placeholder の環境** (where 句 `F: Foo<'x>` での
  `for<'tcx> F: Foo<'tcx>`、hrtb-higher-ranker-supertraits.rs)、**束縛の下の正規化** (`for<'a> <T as Tr<'a>>::Assoc`)。
- その 42 以前のもの: #166–#171 を参照。
