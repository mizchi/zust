# リージョン (ライフタイム) 検査、その 39: dyn Error の `is`、deref を通して代入する let、fn ポインタとして持つクロージャ、トレイトのメソッドの省略された結果 (issue #169)

日付: 2026-11-26

その 38 ([2026-11-26-01](2026-11-26-01-region-check-38.md)) は #237 でマージした。この段階は、ライフタイムのテストを
借用検査の前で止める #169 の型検査の穴の続きと、その 38 が残した穴、トレイトのメソッドの省略された結果を扱う。

## 1. 加えたもの

- **`<dyn Error + 'static>::is`。** prelude の `Error` に、実装する型の `TypeId` を返すデフォルトメソッド (impl ごとの
  デフォルトのインスタンス) を足し、`impl dyn Error + 'static { fn is<T: Error + 'static>(&self) -> bool }` が
  オブジェクトの vtable を通してそれを `T` のものと比べる。そのヘッダは `'static` を書くので、より短いライフタイムの
  オブジェクトを通した呼び出しは、その 38 が `impl dyn Tr` について確かめるのと同じく、呼び出しでの rustc の E0521 で
  ある (regions/regions-static-bound-on-type-param.rs: `err: &dyn Error` での `err.is::<T>()`)。以前は `is` が
  見つからなかった。
- **deref を通して後で代入する `let`。** `*x` の型の推論は、Deref の impl の行き先 (RefCell の `Ref`、`Rc`、
  ユーザーの `impl Deref for W`) と、コンパイラが知る String (`str`) と Vec (`[T]`) の deref をたどる。そのため
  `let p; { let b = m.borrow(); p = &*b; }` は p の型を知り、借用検査は借用されたまま落とされる b を見つける (E0597、
  span/mut-ptr-cant-outlive-ref.rs)。以前は "cannot infer the type of this `let`" であり、`r: Rc<u32>` での
  `let d; d = *r;` は誤った "mismatched types" だった。
- **穴のある fn ポインタとして持つクロージャ。**
  - `let g: fn(_, _) -> _ = |_x, y| y;` で、クロージャを注釈の型に結び付けない: その型には穴があり、結び付けると
    クロージャがその型になり、引数が後の使い方 (`fn(&'a u32, &'b u32) -> &'a u32` として返す `g`) から何も知らな
    かった。"cannot infer the type of this closure parameter" だった。
  - リージョン検査: 値が引数の 1 つであるクロージャは、その引数をポインタの結果へ流す。`fn(&'a u32, &'b u32) -> &'a
    u32` として返すと、`|_x, y| y` は `'b: 'a` を求める: rustc の行での "lifetime may not live long enough"
    (nll/mir_check_cast_closure.rs)。たどるのは、本体がその引数そのものであるものだけである。ほかの本体が何を返すかを
    検査は知らない。
- **トレイトのメソッドの省略された結果。** トレイトの宣言の `&self` は、Rust の省略と同じく、メソッドの省略された
  結果を受け手の借用に結び付ける:
  - vtable を通して: トレイトで `fn get(&self) -> &u8` と宣言したときの、ローカルの `Box<dyn Tr>` の `b.get()` を
    返すのは E0515 である;
  - `impl Ext for dyn Tr {}` を通したデフォルトとして: `x: &(dyn Tr + 'static)` の `x.get()` を `&'static u8` として
    返すのは "lifetime may not live long enough" である。

  以前は結果の領域が新しいものだったので、どちらも受理していた (その 38 のレポートが挙げていた)。

## 4. まだ扱わないもの

- **何も呼ばないジェネリックな関数** (`fn f<T: Tr>(t: &T) -> &'static u8 { t.get() }`): ここではその本体を
  リージョン検査しないので、プレースホルダのメソッドの結果を `'static` として返すことを報告しない。
- **ほかのクロージャの本体が返すもの**: 本体が引数の 1 つでない、fn ポインタとして持つクロージャは、そのポインタの
  結果に引数の領域を与えない (`|x, y| if c { x } else { y }`)。
- **メソッドの受け手の、省略されたライフタイムを持つ self 型** (`impl Pair<&str, isize>` での `self: &Pair<&str,
  isize>`): rustc の E0308 (lifetimes/elided-lifetime-mismatch-in-self-type.rs)。いまの検査は、受け手が書く
  ライフタイムの引数だけを比べる。
- **結果の中の射影についての、シグネチャの implied bounds** (`<fn(&'a T) as HasArg>::Arg = &'a T` での `fn mk<'a,
  T>(r: &'a T) -> D<fn(&'a T)>`): 誤った E0309 (borrowck/alias-liveness/drop-liveness-invariance-issue-160670.rs)。
  #168 のものである。
