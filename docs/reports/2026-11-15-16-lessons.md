# Things learned along the way

Date: 2026-11-15

- **On cold builds, all the syn ASTs for item summaries were kept, so RSS reached 162MB at 5000 functions**.
  Making the item summary parsing parallel and discarding the ASTs inside the threads brought RSS to 35MB, and cold from 855ms to 526ms.
- **The first version parsed the whole file with syn**. So even a no-op took 114ms, and on cold builds each parallel thread re-parsed the whole file, bringing RSS to 191 MiB.
  Switching to the own lexer and the item summary cache brought no-op to 12ms and cold RSS to 39 MiB.
- **Linking was dominated by the number of process stages in the cc driver**. cc + lld takes 21ms, starting ld.lld directly 17ms, starting wild directly 5ms.
- Cranelift's `single_pass` regalloc compiles fast, but execution is about 40% slower (table above).
