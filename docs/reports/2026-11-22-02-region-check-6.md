# Region (lifetime) checking, part 6: placeholders' regions everywhere, and the borrow check's mutability (issue #1)

Date: 2026-11-22

Part 5 ([2026-11-22-01](2026-11-22-01-region-check-5.md)) was merged with #42. Its placeholder's region was a fresh
variable wherever no value of the parameter's type carried it. This step makes it the same region wherever its type
is, checks more of what nothing calls, and adds the borrow check's mutability rules that the failing tests about
borrows needed most.

## 1. What was added

### Region check

- **A placeholder's region, wherever its type is:** a type written as an argument (`with_restriction::<T>(x)`) or in an
  annotation (`let _: &'static T;`) has the placeholder's universal region, not a fresh one.
  - The gate counts a placeholder's region, so a fn whose parameters have no region but its `T` is checked.
  - E0311 when the region the placeholder must outlive has no name (`'_`).
- **Bounds that write lifetimes:** a placeholder's method of a bound `G: GetRef<'a, isize>` is called with the trait's
  lifetimes set to those the bound writes.
  - What the trait's declaration requires (`fn method<'y: 'x>`) is the caller's to prove.
  - A type parameter of the trait that the arguments do not solve (the `T` of `GetRef<'a, T>`) comes from the
    instantiated signature.
  - A fn that calls such a method gets a placeholder instance: its call says something of the regions.
- **Trait default methods:** a trait's default method that no impl uses is checked with a placeholder `Self` bounded by
  the trait. Its calls of the trait's methods take the trait's lifetimes by name (`self.a()` with
  `fn a(&'a self)` in `fn b(&self)` is "lifetime may not live long enough").

### Borrow check

- **`ref` bindings:** the binding of `ref x` / `ref mut x`, or one by reference of the default binding mode, is not
  `mut` itself: `&mut x` of it is E0596.
- **Immutable statics:** an assignment to a static not declared `mut`, or to a part of one, is E0594.
- **Slices by range:** `&x[a..b]` / `&mut x[a..b]` is a loan of x's elements. It is E0596 behind a `&`, and it conflicts
  as `&x[i]` does.
- **Many borrows of a local not `mut`:** two or more are one error at its declaration, after the function's other
  errors, as rustc reports them.
- **Closures:**
  - one that mutates what it captures is `FnMut`: a call of it by name borrows it mutably (E0596 when its binding is not
    `mut`). `&mut x;` in its body is such a mutation.
  - one that holds a `&mut` of a capture is not `Copy` (E0382 when it is moved twice).
  - one whose body moves a capture that is not `Copy` out of itself (`|| drop(v)`) is `FnOnce`: a call of it by name
    takes it (E0382 when it is called again).
- **Arrays matched by value:** `let [_, _, x] = a;` moves `a[2]`, a place of its own, and `rest @ ..` the elements
  between. An array pattern tests nothing of the array itself.
- **`for x in v`:** a Vec or an array by value (not `Copy`) is taken by the loop. A use after it is E0382.
- **Closures where `Fn` is wanted:** a closure passed where a bound wants `Fn` may not mutate what it captures: E0594
  for an assignment, E0596 for a `&mut` or a `&mut self` method (in a closure inside it too), at the mutation.

### Review of #43

- An index (`&a[2]`) reads an array pattern's moved element (`let [_, _, s] = a;`).
- A move closure that only mutates a capture that is not `Copy` (`move || s.push_str("x")`) is `FnMut`. The test for
  `FnOnce` looks for a method that takes `self`, or a pattern that binds a part by value, in the macros' arguments too.
- `m::N = 1` of an immutable static in a module is E0594, as `N = 1` is.
- Another type parameter of a trait's default method (`G: Get<'b>`) keeps its bound's lifetimes; only `Self` takes
  the trait's.
- A closure passed by name where a bound wants `Fn` / `FnMut` (`wants_fn(c)`) is E0525 at the closure, when it is only
  `FnMut` / `FnOnce`.
- `for x in v.iter().copied()` / `.cloned()` does not take v. It also emptied v at run time (v.len() was 0 after the
  loop), and `.cloned()` now clones each element (a `Clone::clone` of a reference to it), not a copy of its bits.

## 4. Not covered yet

- **Tail expressions' temporaries:** a temporary of a block's tail expression lives to the end of the enclosing
  statement, after the block's locals (before edition 2024). One that borrows a local of the block is E0597
  (`nll/issue-54556-*`). zustc has no notion of the edition yet.
- **Projections and `impl Trait`:** as in part 5.
- **Constant conditions:** the borrow check's graph takes one edge of a constant condition, so `false || { i = 5; true }`
  initializes i for it (rustc: E0381).
