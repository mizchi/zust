# Split the LSP out of zustc (2026-11-17)

Date: 2026-11-17

- Moved symbols and navigate from zust-syntax into a new crate, zust-ide (no editor-oriented code in the compiler layers; it is also not
  part of the layers that zustc compiles itself (base–core)).
- zust-analyzer is now the binary `zust-analyzer`. `zustc lsp` is removed; it prints a pointer and exits. zustc (CLI and library) does not
  depend on zust-ide / zust-analyzer (it does not appear in `cargo tree -p zustc`). Only the bench's lsp/* uses them, as a dev-dependency.
- The LSP tests moved to crates/analyzer/tests/lsp.rs.
