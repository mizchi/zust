# Incremental builds of generated programs (N = 1000 / 5000)

Date: 2026-11-15

## N = 1000 functions (320KB)

The environment is a Linux x86-64 cloud container (about 4 cores). rustc 1.97.0, wild 0.10.0, Cranelift 0.137.
Measured with programs of "N functions + mutual calls" generated by `bench/gen.py`. The output of every tool matched the result of running the rustc build.

| tool | cold ms | no-op ms | 1-function edit ms | peak RSS (cold) | binary | cache / incr dir |
|---|---:|---:|---:|---:|---:|---:|
| zustc (starting wild directly) | 128 | 11.7 | **19.0** | **13.4 MiB** | 413 KiB | **498 KiB** |
| zustc (starting bfd directly) | 129 | 12.1 | 33.2 | 13.2 MiB | 422 KiB | 498 KiB |
| zustc (starting lld directly) | 141 | 12.0 | 36.7 | 58.7 MiB | 412 KiB | 498 KiB |
| rustc `-Cincremental -Cdebuginfo=0` | 887 | 217 | 461 | 164 MiB | 5013 KiB | 22151 KiB |
| rustc `-Cincremental -Cdebuginfo=2` | 1015 | 218 | 563 | 183 MiB | 5557 KiB | 24592 KiB |
| rustc `-O` (reference, non-incremental) | 12445 | - | - | 147 MiB | 382 KiB | - |

## N = 5000 functions (1.6MB)

| tool | cold ms | no-op ms | 1-function edit ms | peak RSS (cold) | binary | cache / incr dir |
|---|---:|---:|---:|---:|---:|---:|
| zustc (starting wild directly) | 497 | 63.6 | **87.0** | **34.4 MiB** | 2030 KiB | **2479 KiB** |
| zustc (starting bfd directly) | 471 | 53.9 | 87.0 | 34.6 MiB | 2038 KiB | 2479 KiB |
| rustc `-Cincremental -Cdebuginfo=0` | 3810 | 756 | 1911 | 499 MiB | 8040 KiB | 113644 KiB |

Compared with rustc, a 1-function edit is 20–24 times faster, cold RSS is 1/12–1/14, and the cache is 1/45.
The no-op at 5000 functions takes around 60ms because lexing the whole file, rebuilding the `.o`, and reading and writing the cache are proportional to N.
With multiple files and per-file item summaries, this could also become O(amount of change).

Breakdown of zustc for a 1-function edit (`--time`, N=1000):

| Phase | ms |
|---|---:|
| lex | 2.6 |
| item summary (parse only 1 item) | 1.3 |
| plan | 0.9 |
| cache lookup | 0.5 |
| codegen (1 function) | 0.4 |
| .o generation | 3.6 |
| cache save | 1.2 |
| link (wild) | 5.6 |
| **Total** | **15.9 (peak RSS 12 MiB)** |

The output size of hello (`examples/hello.rs`) is 6.0 KiB with zustc and 333 KiB with rustc debug (stripped).
Most of the rustc output comes from std.
