# Current status (2026-11-15, `python3 bench/vs_rustc.py`)

Date: 2026-11-15

The same source was built with zustc and rustc 1.97.0 using the same steps (cold → no-op → one edit), and the remaining disk usage, binary (after strip) and run time were compared.
The zustc linker is wild 0.10.0. In every combination the output matched rustc `-O`. Full results (including no-op) are in `bench/vs_rustc_result.md`.

- Rebuilding after one edit is 13–24 times faster than rustc incremental (28 ms vs 417 ms on gen1000).
- The remaining disk usage (for zustc, the cache + compressed `.o`; for rustc, the incremental directory) is 1/16–1/210 (105 KiB vs 22156 KiB on gen1000).
- For small programs, binaries are 1/8–1/18 of rustc's (rustc links std statically). gen1000 is larger than rustc `-O` by the amount of the debug checks.
- For run time, zustc debug builds are faster than rustc debug builds in most cases (except gen1000 and fib). zustc `-O` is 1.0–2.9 times rustc `-O` (sort is the same, sieve 1.4 times, matmul and nbody 1.6–1.7 times).
