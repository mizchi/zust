# Region (lifetime) checking, part 4: generic functions nothing calls (issue #1)

Date: 2026-11-21

Part 3 ([2026-11-21-06](2026-11-21-06-region-check-3.md)) was merged with #39. Its last section noted that `zustc
check` checks a generic fn only for the instances requested of it, and that a generic fn nothing calls held the first
error of 120 of the 451 failing tests about lifetimes and borrows. This step checks those functions.

## 1. What was added

- **Placeholder instances:** at the end of the check, each generic fn of the program that no instance was requested
  of is instantiated once more, with a placeholder for each type parameter (`Program::placeholder`).
  - A placeholder is a struct with no fields named `T#`, a name no program's type has.
  - It implements the traits its parameter's bounds name and the auto traits, and is `Copy` when the bounds say so.
  - Left out: a trait's default methods, a closure's body, a dependency's fns.
- **Only marker bounds:** only fns whose type parameters have marker bounds (`Copy`, `Sized`, `Send`, `Sync`,
  `Unpin`) get a placeholder instance. A placeholder has no trait's methods. A fn bounded by more would most likely fail
  its typeck, after the work of it.
- **What is reported:** in this round a typeck error is not reported, as a placeholder cannot do all that its bounds
  allow. The borrow and region checks' errors are reported.
- **What the round follows:** the closures the bodies make, a few levels deep, but not other generic fns' instances.
  `foo(p, |x| f(x))` in foo would never end, and those fns get placeholder instances of their own.
- **Switching it off:** `ZUSTC_NO_PLACEHOLDERS=1` leaves the round out.

Found on the way:

- **`_` parameters:** two `_` parameters are now two locals for the region check (`_#k`). Before, the second hid the
  first's implied bounds, so `fn foo<'a, 'b>(_: &'a &'b (), v: &'b u8, _: &()) -> &'a u8` was rejected.
- **Fields not known:** a struct literal of a type whose fields are not known (of a placeholder's associated type) is
  an error, not a panic.
- **Calls into impls that write lifetimes:** a generic fn's instance calling the method of such an impl
  (`impl Trait<'static> for ()`) is not followed. The generic body called the trait's method under its own bounds
  (`(): Trait<'a>`), with the trait's signature, not the impl's.
- **Review of #39 (minor):** block comments nest in the lifetime lints' scan. The count of a signature's input
  lifetimes goes on past a type it does not know.

## 4. Not covered yet

- **Placeholder regions:** a placeholder has no region. `T: 'a` and the E0310 / E0309 tests need a type parameter's
  region as a universal region, bounded by its `T: 'a` bounds.
- **Bounds with methods:** a bound's methods and coercions of a placeholder to `dyn` are missing. They need the trait's
  signatures, not an impl's.
