# Region (lifetime) checking, part 5: a type parameter's region (issue #1)

Date: 2026-11-22

Part 4 ([2026-11-21-07](2026-11-21-07-region-check-4.md)) checks a generic fn nothing calls with a placeholder type
for each type parameter. That placeholder had no region, so `T: 'a` meant nothing, and the E0310 / E0309 tests ("the
parameter type `T` may not live long enough") could not fail. This step gives it one.

## 1. What was added

- **A placeholder's region:** a placeholder has one region, covariant. It stands for what the parameter's values may
  borrow. In its instance the region is universal, named as the placeholder (`T#`). It outlives what the parameter's
  `T: 'a` / `T: 'static` bounds name, and what the parameters' types imply (`&'a T` implies `T: 'a`).
- **The error:** a placeholder's region that must outlive another is "the parameter type `T` may not live long
  enough": E0310 for 'static, E0309 otherwise.
  - Example: `outlives(cell, t)` with `fn outlives<'a, T: 'a>(..)` in a fn whose `T` has no `T: 'a`.
  - Example: `Box::new(v)` returned as `Box<dyn X + 'static>`.
- **Cost on the hot path:** `lts_of` reads a placeholder only once one was made (an atomic flag), so the hot path does
  not lock the struct table otherwise.
- **Bounds that are traits:** a fn whose type parameters are bounded by traits gets a placeholder instance when its body
  calls none of the methods those traits declare (`Box::new(v)` into `Box<dyn X>`).
  - A call of them would check only the trait's declaration, and its typeck is the cost. On the patterns input, four
    such fns cost +0.5%.
  - A placeholder's method resolves to its bounds' trait's declaration; a trait of a module is found by the last name
    of its path.
  - A trait method with no body is called for a placeholder `Self`. Its instance is not compiled.
- **Unsizing casts:** `Box::new(v) as Box<dyn Tr + 'static>` is a coercion. The value flows into the type written.
- **`dyn Tr + '_`:** in a signature it is an elided lifetime, a fresh one at each call. It is not the default, which in
  `Box<dyn Tr>` is 'static. A signature that writes only that `'_` used to read as having no regions, so
  `get_v(Box::new(h) as Box<dyn G>)` with `fn get_v(gc: Box<dyn G + '_>)` was rejected.
- **E0594 and its kind (review of #40):** the borrow check's kind of errors that lowering itself returns (E0594 for
  `m[&k] = v` of a HashMap, `cannot borrow`, E0596, E0384) are reported in placeholder instances too, not left out
  with the typeck errors.

## 4. Not covered yet

- **Projections:** the region of a projection of a type parameter (`<T as Tr>::Output: 'a`). A placeholder has no
  associated types, so those fns are not checked (`nll/ty-outlives/projection-*`).
- **`impl Trait` results:** the regions an `impl Trait` result captures (`type_parameters_captured`).
- **Async fns:** their placeholder instances.
